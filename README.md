# محوّل — PDF والصور إلى Word و Excel و PowerPoint

تطبيق ويب يعمل محليًا بالكامل: يحوّل ملفات **PDF** وال**صور** إلى ملفات Office قابلة للتعديل، دون رفع أي بيانات إلى خدمة خارجية.

## التشغيل

```bash
# 1) تثبيت المكتبات (مرة واحدة)
python -m pip install -r requirements.txt

# 2) تشغيل الخادم
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

ثم افتح <http://127.0.0.1:8000> — أو انقر نقرًا مزدوجًا على `run.bat` في ويندوز.

## التحويلات المدعومة

| من | إلى Word | إلى Excel | إلى PowerPoint |
|---|---|---|---|
| PDF نصي | تنسيق محفوظ: فقرات، جداول، صور | ورقة لكل صفحة/جدول | شريحة لكل صفحة |
| PDF ممسوح (Scan) | **نص عربي حقيقي + جدول Word** | **جدول Excel بخلايا حقيقية** | شريحة لكل صفحة |
| صور (PNG/JPG/WEBP/BMP/TIFF/GIF) | **نص عربي حقيقي** | **جدول Excel بخلايا** | صورة في كل شريحة |

- **OCR مدمج:** يستخدم محرّك `Windows.Media.Ocr` الموجود في ويندوز (لغة `ar-SA`) — بلا تنزيل ولا إنترنت ولا مفاتيح API.
- **تنسيق مطابق للأصل** (مفتاح مستقل في الواجهة): يُبنى ملف Word بقياسات الملف الأصلي —
  أبعاد الصفحة نفسها، عرض كل عمود وارتفاع كل صف من خطوط الجدول، حجم خط كل خلية من ارتفاع كلماتها،
  ومحاذاة كل سطر (يمين/وسط/يسار) حسب موضعه في الصفحة. النتيجة صفحة Word لكل صفحة أصلية.
- **الخطوط:** يُستخدم `Arabic Typesetting` للنصوص العربية (قريب من خط النسخ في النماذج الرسمية)
  و`Arial` للأرقام والنصوص اللاتينية؛ الأحجام مُعايرة من ارتفاع الحروف في المسح الأصلي مع تباعد
  محسوب يحافظ على عدم زيادة عدد الصفحات.
- **كشف تلقائي:** يُقارن النص المخزّن في PDF مع نتيجة OCR لعيّنة من الصفحة؛ إن كانت طبقة النص غائبة أو مشوّهة يُستخدم OCR.
- **جداول حقيقية:** تُستخرج خطوط الجدول من الصورة (OpenCV) فتُبنى الخلايا بحدودها الفعلية، لا بالتخمين.
- تعطيل مفتاح OCR من الواجهة يعيد السلوك القديم (إدراج الصور كما هي).
- اختيار عدة صور معًا يدمجها في ملف واحد.
- اختيار عدة ملفات PDF (أو خليط PDF + صور) يُنتج ملفًا لكل مدخل داخل ملف ZIP.
- الحدود: 30 ملفًا، 120 ميجابايت إجمالًا، 300 صفحة لكل PDF.

## البنية

```
muhawwil/
├── main.py            خدمة FastAPI: استقبال، تحقق، تنظيف تلقائي للملفات
├── converters.py      محرّك التحويل (pdf2docx, pdfplumber, python-docx, openpyxl, python-pptx, PyMuPDF)
├── ocr_engine.py      محرّك OCR: Windows OCR + كشف خطوط الجدول + تحليل التخطيط
├── static/
│   ├── index.html     الواجهة (عربية RTL)
│   ├── style.css      التنسيق + مظهر ليلي
│   └── app.js         السحب والإفلات، الرفع مع نسبة تقدم، التنزيل
├── samples/           ملفات تجريبية للاختبار
└── run.bat            تشغيل سريع في ويندوز
```

## ملاحظات

- دقة OCR العربي جيدة لكن ليست مثالية: الأرقام المتشابهة (`11` قد تُقرأ `ll`) وبعض الهمزات قد تحتاج مراجعة سريعة.
- OCR يعمل على ويندوز فقط (محرّك النظام). على أنظمة أخرى يلزم Tesseract أو خدمة سحابية.
- تحويل Excel للصور عند تعطيل OCR يُدرج الصور كأرشيف مرئي داخل الخلايا.
- الملفات المؤقتة تُحذف تلقائيًا بعد كل عملية تسليم.
